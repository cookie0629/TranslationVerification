# Язык Funny

[RU|[EN](funny.md)]

Funny позволяет пользователю описывать *модули*. Модуль состоит из именованных [*функций*](#функции-и-типы) и [*формул*](#определения-формул).

## Предыстория и обоснование Funny

Цели языка:

1. Простота синтаксического разбора.
2. Простота компиляции в выбранное низкоуровневое представление.
3. Достаточная сложность, чтобы демонстрировать верификацию императивных программ.

Отсюда: несколько возвращаемых значений, неизменяемые параметры, явные области видимости, формулы в дополнение к функциям.

## Основы языка

Пробелы/табуляции/переводы строк эквивалентны одному пробелу. Комментарии `// ...` до конца строки считаются пробелами.

### Типы и константы

- `int` — математические целые (в логике) и 32-битные знаковые при исполнении (переполнение по модулю 2^32).
- `int[]` — массив целых; длина неизменяема во время выполнения, `length(a)` возвращает длину.
- Логические константы `true`/`false` и булевы операции используются в условиях и предикатах;
  отдельного типа `bool` для переменных нет.

### Идентификаторы

Идентификаторы начинаются с латинской буквы и содержат буквы/цифры. Присваивание массивов имеет семантику копирования:
`b = a;` создает копию массива.

### Исключения

- Деление на ноль.
- Доступ к массиву вне границ.

Обработки внутри языка нет; перехват возможен во внешнем коде.

## Функции и типы

Все функции экспортируются. Синтаксис:

```EBNF
function = identifier
    "(" [ variableDef {"," variableDef } ] ")"
    ["requires" predicate ]
    "returns" variableDef {"," variableDef }
    ["ensures" predicate ]
    [ "uses" localVarDef {"," localVarDef } ]
    statement;

variableDef =
    identifier ":" variableType;

localVarDef =
    identifier [ ":" variableType ];

variableType = "int" | "int[]";
```

- Параметры/возвраты требуют явного типа.
- Локальные переменные могут опускать тип; компилятор выводит его из первого корректного присваивания (см. ниже).
- Имена параметров, возвратов и локальных переменных уникальны в пределах функции.
- Функции можно вызывать рекурсивно; имена уникальны в модуле.

### Пред- и постусловия

- `requires` использует параметры; по умолчанию `true`.
- `ensures` использует параметры и возвращаемые значения; по умолчанию `false` (для задания явных требований).

### Определения формул

Формулы используются только в предикатах:

```EBNF
formula = identifier "(" [ variableDef {"," variableDef  } ] ")" "=>" predicate;
```

## Операторы

Типы операторов:

```EBNF
statement = assignment | conditional | loop | block | assertStmt | assumeStmt;
```

### Оператор присваивания

```EBNF
assignment =
    varName "=" expr ";"
  | arrayAccess "=" expr ";"                     (* синтаксический сахар для функционального обновления массива *)
  | varName { "," varName } "=" functionCall ";"
```

Параметры функции (включая массивы) доступны только для чтения и не могут быть в левой части присваивания.
Локальные переменные и возвращаемые значения доступны для чтения/записи; чтение неинициализированного — неопределено.

#### Обновление массива: синтаксический сахар

`a[i] = v;` обессахаривается в функциональное обновление с копированием:

```funny
a[i] = v;      // эквивалентно a = set(a, i, v);
a[i][j] = v;   // эквивалентно: tmp = a[i]; tmp = set(tmp, j, v); a = set(a, i, tmp);
```

Функция `set` — часть семантического описания, не публичного API.

### Условный оператор

```EBNF
conditional = "if" "(" condition ")" statement ["else" statement];
```

### Оператор цикла

```EBNF
while = "while" "(" condition ")"
    [ "invariant" predicate ]
    statement;
```

Если инвариант опущен, считается `true`.

### Блочный оператор

```EBNF
block = "{" { statement } "}";
```

Точка с запятой — часть присваивания, не разделитель.

### Операторы `assert` и `assume`

```EBNF
assertStmt = "assert" predicate ";"
assumeStmt = "assume" predicate ";"
```

`assert` проверяется при верификации (и опционально в рантайме); нарушение — ошибка. `assume` сужает пространство
состояний для верификации; в рантайме может игнорироваться или проверяться по флагу.

## Выражения

```EBNF
expr =
    functionCall
  | arrayAccess
  | number
  | variable
  | "-" expr
  | expr "+" expr
  | expr "*" expr
  | expr "-" expr
  | expr "/" expr
  | "(" expr ")";
```

### Вызов функции

```EBNF
functionCall = identifier "(" [ expr {"," expr} ] ")";
```

Функции с множественным возвратом недопустимы внутри выражений — только в присваивании кортежа. Аргументы вычисляются
слева направо. Типы/количество аргументов должны совпадать с объявлением. Встроенная функция
`length(a: int[]) returns l: int`.

#### Обращение к элементу массива

```EBNF
arrayAccess = varName "[" expr "]"
```

Переменная должна иметь тип `int[]`, индекс — `int`. Выход за границы — исключение.
Обновление через `a[i] = v` — функциональное копирование (см. выше).

## Условия

```EBNF
condition =
    "true" | "false"
  | comparison
  | "not" condition
  | condition "and" condition
  | condition "or" condition
  | condition "->" condition
  | "(" condition ")";

comparison =
    expr "==" expr | expr "!=" expr
  | expr ">=" expr | expr "<=" expr
  | expr ">" expr  | expr "<" expr;
```

Приоритет: `not` > `and` > `or` > `→`. Импликация правоассоциативна.

## Предикаты

```EBNF
predicate =
    quantifier
  | formulaRef
  | "true" | "false"
  | comparison
  | "not" predicate
  | predicate "and" predicate
  | predicate "or" predicate
  | "(" predicate ")";
```

### Кванторы

```EBNF
quantifier = ("forall" | "exists") "(" variableDef "|" predicate ")";
```

Имя переменной квантора уникально в области: `requires` — параметры; `ensures` — параметры+возвраты;
`invariant` — параметры, возвраты, локальные.

### Ссылки на формулы

```EBNF
formulaRef = identifier "(" [ expr {"," expr} ] ")";
```

## Вывод типов локальных переменных

- Тип локальной переменной без аннотации выводится из первого присваивания.
- Контекст задаёт ожидания: арифметика/сравнения/индексы требуют `int`; `length(x)` и `arrayAccess` возвращают `int`;
  вызовы функций имеют объявленные типы.
- Пример обессахаривания фиксирует типы массивов: `a[i]=42;` → `a: int[]`, индекс — `int`.
- Если тип не удаётся вывести или вывод противоречив — семантическая ошибка. Параметры и возвращаемые значения всегда
  аннотируются явно.
